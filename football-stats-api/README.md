# ⚽ Football Stats API

Football Stats es una aplicación desarrollada con Node.js y Express que permite consultar y administrar información básica de equipos de fútbol.

El proyecto cuenta con una API y una interfaz web sencilla para interactuar con los datos.

## 🚀 Funciones

La aplicación permite:

- Consultar todos los equipos.
- Consultar un equipo por su ID.
- Buscar equipos por nombre.
- Comparar los títulos de dos equipos.
- Agregar nuevos equipos.
- Eliminar equipos.
- Visualizar la información desde una página web.

## 🛠️ Tecnologías utilizadas

- Node.js
- Express
- HTML
- CSS
- JavaScript
